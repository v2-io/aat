# Influx dispositions

*Append-only. This is the store's one way of taking in material from any source: one entry per disposition, saying what came in, from where (path and commit in the source), what it became here, what was left behind and why, and what the disposition found in the source. Outcomes and reasons only; it never restates `ls`. ASF is a source like any other; if it keeps changing, that is more influx, disposed the same way. "Copy as-is" is one possible outcome. There is no migration tool and nothing here is transitional.*

Sources so far: **ASF**, `~/src/arch/asf/`, read at `2133cf2ee1ab0d3cced0c74c3e266e5994113929` (2026-11-02). ASF was not modified by any disposition.

Outcomes used: **integrated** (became a record here) · **left** (stays in ASF; reason given) · **carried as finding / question / item** (became a vsect record of that kind) · **needs-review** (crossed, but a judgment in the crossing is flagged for a second mind).
