## Seams in ASF's machinery that v3 should not inherit uncritically (my reading)

1. **`stage:` is dead weight by ASF's own admission.** FORMAT: "the stage layer is known to go stale quickly … and is currently ignored in practice … the gating methodology itself is under reconsideration". Memory `feedback_stage_gating_known_problematic`: Joseph ignores `stage:`.
2. **`status:` is hand-typed epistemic strength** and FORMAT says "Tier comes from frontmatter, not Findings". The 09-29 census (aat-refactored PROPOSAL) found `der-recursive-update` flipping exact→conditional→exact with unchanged Epistemic Status. Hand-set labels = proxies that drift; spikes.sop §0 says exactly this about every artifact label — ASF's frontmatter is the one place the doctrine wasn't applied to itself.
3. **Cadence exemption for intro/disc segments** "until dedicated norms for those file kinds are worked out" — an acknowledged gap in the kind-system (the 09-29 proposal's "discussion splits four ways" is one attempt to fill it).
4. **`type:` has 19 values** incl. several no segment uses (`corollary`, `aside` per the 09-29 census) and some that are reading-order roles not kinds (`detail`, `sketch`). FORMAT's own "Why these labels" is register-anxiety (postulate/result/derivation chosen to avoid sounding like math originality) which agents.sop's "Math-novelty recognition — do not deflate" partly contradicts.
5. **Spike/audit routing is mature and scarred** — this is the part of ASF most worth porting nearly whole: truth-arbiter §0, §0c discharge, no-go protocol, regression axis, independent-verify gate, gold standing gate, meta-stance asymmetry. Its weakness is that it is *procedure enforced by agents remembering it* (the second aat-refactored coordinator: "Laws enforced by agents remembering them fail as often as memory does"; "Porcelain is where truth-keeping actually happens").
6. **"Segment never lies about its own status, even transiently" (routing 4.1)** is the deepest invariant; ASF tries to satisfy it with hand-edited labels + FALSE marks. RC1/porcelain thinking aims to make it structural (computed projections, ⚠ known-broken shown first).
