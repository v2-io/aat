## What it is (README, read whole)

> Working name (2026-08-05) for **outline + segments** structures: stable atoms (segments; slug = identity), an outline as exposition **view** (order, membership, view-local metadata), and epistemic state carried honestly per atom — the pattern that keeps establishing itself across this estate because it is a **solution to 100% agentic turnover in highly complex, living creation projects**.

Telos (verbatim): **"Session success = a truthful segment drafted, corrected, or strengthened — or an open item honestly discharged."** Two laws: **the delete-test** and **proxy-discipline**. "When delegating: orient agents to this telos before the task — subagents optimize whatever finish-line they're handed, so hand them this one."

Two products: (1) the theory instance (`theory/` — OUTLINE "Foundations / the Nine Organs / the Process Dual", 35 `src/` segments of which ~23 drafted, rest `pre-drafted` WN-only stubs; huge `influx/`); (2) the deployment **template** (`template/`).

Known deployments: asf (spiritual ancestor), vivarium, relata, comproprium, udon/v2/paths (now `address-theory`, deployment #2), deployment #3 (2026-08-12, "the kit's first outside consumer" — find which). `.archive/theory-misfire/` = prior founding attempt, **deliberately avoided** (steward advisory 2026-08-06: do not mine while foundation is laid) — the "fluency-before-doctrina" founding wound.

Three axes the template exercises:
- **process-state** (ownership): `proposed` / `template` / `override` → then `drafted` etc. ("State-not-Stage").
- **authority** register for directives/references (not truth-apt): `proposed / ratified / ruled` (+ `supported`), with `current` / `-current` as decaying freshness. Shares the "Epistemic Status" column with evidence tiers on truth-apt rows.
- **Max** (ceiling); "A `Max` beside a `proposed` state is a route, not an assertion."

Key template doctrine (from the symlinked segments — each worth carrying into v3 as-is or adapted):
- **def-atom:** atom = smallest independently-adjudicable record; kind per deployment; **one atom per record** ("adjudication grain and record grain must coincide"); identity = slug, never position/number/path.
- **def-atom-cluster:** atom = Body (replacement; present truth) + Working notes (forward-only) + **Events** (append-only: actor, date, criterion, outcome) + Companions (derivations, figures, run records). "An instance without the events part can still carry status tokens; it just cannot answer *who checked what, when, against which criterion* — which is the difference between veritas and assertion."
- **form-slug-form-kinds:** prefixes carry **form-kind only** (def/post/scope/form/norm/claim/obs/meas/disc), never trajectory (hypothesis/derived/empirical/result) — because ASF's type-derived prefixes make "honest updating break identity". `claim-` is trajectory-neutral. Paired forms (`def-X` + `claim-X`; asf's `result-X` + `deriv-X`) are anatomy, not collision. (Steward reservation: "`claim-` worries Joseph a little".)
- **form-state-flags-not-gates:** independent resettable check-flags; no ladder; gates only at genuine destinations (emission seams). Evidence: "115/115 segments at first rung in the most actively worked corpus, the terminal gate never fired anywhere". Test: "updating a well-verified atom must feel like advancement, not regression."
- **post-names-are-interface** + **claim-naming-criteria** (10 axes incl. standalone citability w/ 4 repair moves, coinage-necessity test).
- **form-influx-membrane:** nothing writes the population directly; manifest + payloads; typed outcomes (rejected = submitter erred / needs-review = system uncertain / skipped).
- **def-integration-replacement:** per-store **write semantics** declared (replacement corpora vs append-only accounts); **delete-test**; `.integrated/` vs `.archive/` as truth-claims; **graduation-completeness** (a clean present surface can't prove a complete past dispatch).
- **claim-dispatch-compounds:** residue is a per-reader tax; bifurcation hypothesis (clean vs residue attractor; **false nuggets** train the widening loop).

## Bearing on v3 (my reading, provisional)

- The template is a **shell + generic doctrine** — it deliberately ships no epistemology (the --GAP-- row) and no kind taxonomy. RC1 is where those were worked out *after* the template was cut. So deploying the template to aat-v3 as-is would hand AAT the frame without the part that most needs to be right; v3 needs template ⊕ RC1 (with RC1 still `proposed`) ⊕ ASF's mature routing/audit SOPs.
- Udon dependence: def/ entries, PRACTICA, DECISIONS are `.ud`; md-press doesn't cover udon. spec-lite-0.1.0 is (I expect) the udon that these surfaces will be written in — hence Joseph's third read.
- ASF→template mapping questions to resolve: ASF `type:` (19 values, trajectory-mixed) vs form-kind prefixes; ASF `stage:` vs state flags; ASF `status:` vs evidence-tier + authority + Max; ASF's per-segment Findings vs ?; ASF's huge WN gold vs "working notes forward-only".

## RC1 — `theory/influx/segments-model-rc1/` (all .md read whole 2026-10-28: 00, 01, 02, 03, 04, 06, 07, 08, 09, 10, 11, 90, 95, SPECIMEN, lang/README; NOT yet read: lang/rc1-in-udon.ud (341), vsl.py, specimen.vsl, and the parent influx's rc1-denovo-read / rc1-grok-read / rc1-coord-wanderings / rc1-working-praxes / verisect-and-ldocs)

Register: everything `proposed`, none ratified; 09 is `sketch`. Lives in influx (not canon) by design: "when its shape is ratified, content drafts into `theory/src/` and these files become pointers."

**The model in one paragraph (00, verbatim):** *"A record's kind is individuated by how it fails and what repairs it, and adjudicated on its kind's epistemic dimensions — the questions its soundness consists in; its state is the trail of securing acts performed on it, with every status a computation over that trail — never a hand-set word. Truthification is the cycle that runs those acts: ..."*

Core commitments (with file pointers):
- **01 Altitude 1** three consequences of total turnover: every record says how strongly it's held and why; honesty only defined relative to kind; "The only status a stranger can trust is one they can recompute."
- **Kinds individuate by failure-and-repair** (01, 02 KIND, 10 Q2–Q3). Speech-acts: assert / decide / record / prescribe / ask / refers / teach / commit.
- **Epistemic dimensions** (03) = unit of orthogonality, named `namespace/dimension` (namespace is NOT an object). Table: Evidence (derivation / in-vivo / wild-empirical / instance / testimony / carriage), Backing (decision/grounding, consultation, accountability, falsifiers), Fidelity (substrate, not peer), Efficacy, Comprehension, Conviction, Freshness, Disposition. **Only Evidence/Backing/Fidelity are matured; five are hypotheses "wearing full rows".** Fusion tell: unrolled-permutation ladders. **Substitution law**: no dimension's value substitutes for another's (authority ↛ truth; endorsement ↛ firing; beautiful explanation ↛ support; commitment ↛ soundness; corroboration ↛ witness position; traceability ↛ adequacy).
- Admission adjudication (03): bounds (usage/claim license, audience-safety/priming, conflict precedence) vs gates (standing; publication membrane) vs machinery (kind, process flags, ownership, grain, ceiling, coverage, exposition weight).
- **Anatomy** (02): RECORD {KIND, BODY, WORKING-NOTES, TRAIL, COMPANIONS}; DIMENSION; LINE; EVENT (channel · actor+authority · criterion · criterion-commitment pre/post · date · outcome · era-key); TRAIL (append-only); PROJECTION (computed; order-invariant; declared — strongest-line / every-line-sustains / shown-independent-agreement; "a `@{generator}` evaluated as of a moment"); LADDER (signed channels; ceiling; certificates decay); ERA.
- **Foundation × exercise** plane: "Everything a generative mind writes is born at sensibility … The cardinal sin is not being low on either coordinate; it is reporting a position you don't occupy." Mirror: **under-recording is as dishonest as an unwarranted lift** (steward), poisons absence-semantics → **decline-events** for deliberate non-lifts.
- **Cycle** (04): ORIGINATE (corrective / generative / decision-inflection) → MINT (foundation declared; "the instrument follows the ground") → SECURE (lines; signed ladders; refutation = result) → RECORD (order-invariant) → LAND (identity persists, body replaced, trail keeps history) → SERVE (license) → MAINTAIN (era decay; referent resets). Laws: **coherence default** (agreement weighs only where descent shown cut); **commitment law** (question/design channels free; verdict channel must be pre-committed); transmission = ambient prior via carriage ladder; de-novo audit = manufactured transmission-independent line.
- **Worked ladders for a claim** (04 table) — directly AAT-applicable: `evidence/derivation` sketch → drafted → deps-verified → re-derived (refutes by counterexample → no-go); `evidence/in-vivo` (vivarium!) pre-registered → run-once → swept → independently-reproduced, era-keyed; `evidence/wild-empirical`; `evidence/instance` (worked examples: mapping breaks → scope-bound); `evidence/testimony`; `evidence/carriage` (imported theorems: named-not-read → … → primary-verified, capped at source tier). "analogy deliberately has **no row**: it grounds ideation … never assertion."
- **Decision ladders** (04): grounding / consultation / accountability (proposed → supported → ratified → ruled; terminals rejected/superseded; honesty states defacto/transition) / falsifiers. Guard: *ratified* requires grounding-explicit AND consultation-announced.
- **Edges** (06): supports (strength NOT transitive; notification reach transitive) · rebuts · undercuts · supersedes{revised-by, invalidated-by, alternate-of} · seeded-by (transitive — descent) · narrates · restates{exact, near}. Re-pricing = notification + threshold detection, not mutation (because status is computed). Refuted → hard cascade, known-broken visible immediately; weakened → undercut, soft.
- **07** question lifecycle: posed → routed with declared closer (steward-fact / awaiting-ground / agent-open) → ripens → answered / rejected-with-reopen-condition / superseded-by; asked-and-answered recorded; "Silent loss is the deep failure." Gap value = influence of closing, priced by waiting decisions (EVI). Counterweight: cheap truth is run, not triaged. Ignorance vocabulary: quantified spread → scenario → recognized ignorance.
- **08** certification = named criterion + independent-enough grader + dated event + reproducible check; bounded by grader independence not effort; decays; **verification ≠ validation, never share a cell**; trusted base (reproducibility as fabrication defense; tamper-evident commit stream; actor identity at substrate grain; named trust for testimony). Acceptance protocol: auditor walk on a small corpus; founding dry run; two external checks.
- **09** declarative language (sketch): declare dimension / kind / edge-kind / projection / gate + rule (when/allow/enabling). Three properties: **stating a securing act is recording it**; laws become lint (fusion, substitution, hand-set status unparseable); extension without drift. `lang/vsl.py` spike ran both specimens.
- **10 founding questions Q0–Q8** per record-kind: standing (gate) · speech-act · failure · instrument · dimensions · movers · ceiling+evidence-action · grain+edges · certification ("is it immediately obvious to a de-novo auditor … exactly what should be audited?"). **2026-08-30 strain + proposed repair (not yet ratified):** record boundary test precedes speech-act — *"can this piece fail — be refuted, rot, reopen — while that piece stands?"*; and *"topic → outline · dependency → edges · failure → record boundaries · adjudication → kind & dimensions"*. This is exactly the question a v3 founding must answer for AAT.
- **11** adopts the address-theory (references) lexicon: identity = maintained `@{binding}` (dangle/collide surface); projection = `@{generator}` evaluated as-of a moment ("no untimed evaluation" ⇒ certificate decay derived); edges = `@{reference}` w/ intended cardinality; designator vs description (match); record = referent ≠ manifestation (sub-record grain = inner `@{location}`). `@{moment}` undefined in both corpora.
- **90** fork queue (steward, all open as of last write): Evidence MECE; failure-mode bursts for 5 dims; naming; parked items; auditor walk target; **EPISODE** object (from 95); lexical-core rulings.
- **95** field trial vs live_docs (Samuel Wecker's independent system): corroborations; **RC1 has no EPISODE** — securing acts are usually multi-record (a review, a cascade, a session); proposed EPISODE object w/ per-record trails as projections, only via SPECIMEN #3. Also: "the organs fail to propagate precisely because they cost before they pay" → minimum-viable-rung story needed beside the model.
